# Follow Ruff while using only pyproject.toml

Ruffhouse follows Ruff's `check` command, rule selection, diagnostic shape, JSON fields, and exit statuses so existing Ruff users do not learn another interaction model. Compatibility covers the observable contract rather than byte-for-byte terminal rendering or Ruff's internal renderer. The first release supports full, concise, JSON, and GitHub output and does not offer source fixes. Invalid Python syntax is a finding with exit status 1; configuration, I/O, and internal failures use exit status 2. Ruffhouse reads only `[tool.ruffhouse]` configuration from the nearest applicable `pyproject.toml`; its initial configuration surface is limited to rule selection, per-file ignores, output format, explicit configuration, and isolated operation. Standalone configuration files and broader file controls are omitted until demand justifies them.
