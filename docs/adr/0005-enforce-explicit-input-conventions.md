# Require explicit input calling conventions

GR001 flags positional-or-keyword inputs on non-public module-level functions and methods, while GR005 applies the same policy to the complementary syntactic public bucket. A non-public name starts with an underscore and does not end with one, so the two rules form a complete, disjoint partition without inferring whether an interface is documented or exported. Positional-only (`/`) and keyword-only (`*`) inputs are accepted because both declarations make the calling convention local, deterministic, and runtime-enforced; implicit method receivers and variadic parameters remain excluded. Separate codes let established libraries enable GR001 before reviewing, migrating, or suppressing compatibility-sensitive public and protocol contracts for GR005. The `GR` and `ALL` selectors enable both rules. Both remain opt-in while repository trials establish that explicit input calling conventions reliably reduce review work.
