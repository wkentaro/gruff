# Flag subsumed comments

GR007 flags a one-line own-line comment whose every content word is subsumed by the tokens of the adjacent statement window, so redundancy is decided as a lexical fact rather than a taste call. The criterion comes from five measured iterations over a 17-repo, 1.09 MLOC corpus, recorded in issue #53: a prefix denylist reached 64% precision and was rejected as unstable because one 834-copy generated cluster inflated it, token subsumption reached 90%, own-line-only and annotation-form exclusions reached 96.7%, and non-prose exclusions with assert-line string handling landed at ~97% precision over 661 findings, with a findings-per-KLOC gradient from 0.02 in hand-written code to 0.66 in agent-era code. The stopword list, the 4-line window, the exclusions, and the header floor are frozen by that measurement, including the deliberate divergence from Ruff's pragma-comment prefix set; the synonym map is the sole recall lever, and each added entry requires corpus re-measurement before merging. Multi-line comment blocks, trailing comments, docstrings, stemming or similarity scoring, and configuration options stay outside the rule.

Four `# noqa` lexing decisions are recorded alongside it. A trailing directive is stripped from a comment's body before word extraction, a deliberate deviation from the measured criterion so a suppression annotation cannot supply the extra content word that shields an otherwise-subsumed comment. A directive's hash must open the comment or follow whitespace or another hash, so a hash embedded in a URL or a word never starts one; this is stricter than Ruff on that form, and it is kept because silently swallowing a fragment identifier costs more than rejecting a directive nobody writes. Codes joined without a delimiter, as in `# noqa:GR001GR002`, are rejected rather than split, siding with flake8 because a reader cannot see where Ruff's split would fall. Rule codes match case-sensitively, agreeing with both Ruff, whose lexer accepts only uppercase codes, and flake8, which compares them exactly; Gruff previously suppressed on `# noqa: gr004`, which both tools report.
